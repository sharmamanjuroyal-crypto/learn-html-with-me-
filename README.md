This is my personal learning journal where I upload 10 minutes of daily practice on HTML & CSS. The goal is simple: show up every day, write a little code, and track my progress over time.

🎯 Purpose
Learn HTML and CSS step by step, one small session at a time
Build consistency through daily practice (even just 10 minutes)
Keep a public record of my progress that I (and anyone else learning) can look back on
📅 How it works
Every day, I spend ~10 minutes practicing HTML/CSS
I upload what I built/learned that day into this repository
Each day gets its own folder or file so progress is easy to track
